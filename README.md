## Components
- [Raspberry Pi Zero 2W (with headers)]
- [MicroSD Card]
- [Vinyl Record Coasters]
- [28BYJ-48 ULN2003 5V Stepper Motor & ULN2003 Driver Board]
- [A3144E Hall Effect Magnetic Sensor Module]
- [RC522 RFID Reader Module (with headers)]
- [NTAG213 NFC Tags]
- [5x2mm Magnet]
- [Female to Female Dupont Jumper Wires (16 ct)]
